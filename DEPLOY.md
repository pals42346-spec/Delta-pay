DELTA PAY — DEPLOYMENT
=======================

This folder is a static website and can be published on a static hosting provider.

FASTEST OPTION: NETLIFY
1. Create a Netlify account.
2. Use "Add new site" / deploy manually.
3. Upload this folder (or the ZIP contents).
4. Netlify will provide a public https://... URL.
5. You can rename the site's subdomain in Site settings.

ALTERNATIVES:
- Vercel
- GitHub Pages

IMPORTANT:
This site is a frontend prototype. It does not process real deposits, withdrawals, KYC, or customer funds. Do not advertise the illustrative rates as guaranteed returns or claim a banking/deposit-taking authorization that you do not have.

For a real financial service, connect only compliant providers and publish accurate legal entity, authorization, terms, risk, KYC/AML, privacy and grievance information.
