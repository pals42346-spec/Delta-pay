DELTA PAY — DEMO WEBSITE
========================

HOW TO OPEN
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, Firefox, or another modern browser.
3. No installation or internet connection is required.

WHAT'S INCLUDED
- Responsive Delta Pay dashboard inspired by the reference screenshots.
- Demo deposit calculator with explicitly illustrative rates.
- Simulated activity history, referral overview, and profile page.
- No real payments, deposits, withdrawals, bank/UPI connections, or payout functionality.

IMPORTANT
This is a frontend prototype only. All values and rates are examples and are not a financial offer,
guaranteed return, or promise to pay interest. Do not collect customer deposits using this demo.
Before launching a real financial product in India, obtain qualified legal/compliance advice,
confirm the appropriate regulatory permissions and disclosures, and integrate only authorized,
secure payment and banking providers.
